# Bistro 47

Демонстрационный сайт ресторана по предоставленному референсному изображению.

Сайт содержит адаптивную главную страницу, меню, галерею, отзывы и форму подготовки запроса на бронирование. Форма не отправляет заявку: для подтверждения она предлагает звонок.

Контакты, рейтинг и отзывы воспроизведены из макета и требуют замены на подтверждённые данные перед использованием для реального ресторана.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой локальный сервер статических файлов в этой папке.
